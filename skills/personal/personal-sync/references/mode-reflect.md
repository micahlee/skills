# Reflect Mode

Use for `/personal-sync reflect [DATE|RANGE]`. Reflection notices meaning and patterns; it does not rebuild the plan.

1. Read the target planning note and agent context.
2. Use calendar, tasks, food/health/fitness, Gmail metadata, Axon events, and 1–3 central linked notes when available and relevant.
3. Write a humble first-person synthesis to the agent daily note under `Dream`:
   - snapshot
   - strong signals and possible patterns
   - open questions
   - source coverage
4. Write tomorrow-facing implications under `Tomorrow Nudge` in tomorrow's agent daily note, never in the human daily note.
5. Emit actions or decisions only when evidence is strong and the next step is clear.
6. Roll compact daily themes into agent weekly/monthly context when requested or scheduled.

Use confidence language such as `Strong signal`, `Possible pattern`, and `One-off note`. Do not turn every observation into homework. Preserve human-authored reflection notes wherever they live.
